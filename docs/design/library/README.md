# Glass UI: component library for Home Assistant dashboards

Version: library v1 (Draft v0.3 of the design guide), 2026-11-17. Loader v12.
Format: modelled on the Bootstrap 6 docs (getbootstrap.com/docs/6.0, v6.0.0-alpha.1): Getting started, Customize, Layout, Content, Components, Helpers. One page per part. Each component page has the same sections: purpose, example (config plus a render), anatomy (named sub-parts), options, variants, states, behaviour, accessibility, tokens, do and don't, status.

**Status meanings.** **Locked**: config keys and look are frozen; a change needs the owner's OK. **Draft**: built and measured, waiting for the owner's check on a real device. **Planned**: named, not built.
