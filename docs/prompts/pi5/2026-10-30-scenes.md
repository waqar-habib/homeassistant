## Assumptions and risks

| # | Item | Risk |
|---|---|---|
| 1 | Evening excludes the 3 Nursery lights (owner decision, 2026-10-30) | None for Evening. Good Night and Leaving still switch the Nursery lights off. Tell Claude if a Nursery night light should stay on in those scenes |
| 2 | Locking is physical | A lock scene on a jammed bolt may report an error. Mitigation: owner tests it standing at the door |
| 3 | `scene:` in a package alongside `scene: !include scenes.yaml` in `configuration.yaml` | Both are list-type, so HA merges them. If `ha core check` objects, put the scenes in `scenes.yaml` instead (it is 0 bytes) |
| 4 | Lights from different integrations (aidot, tplink, switch_as_x) | One may not accept brightness. Mitigation: verify state after activation |

Outcomes:
- **Best:** 6 scenes exist, `ha core check` is clean, they appear as buttons in the Nuvio "Scenes and scripts" panel, and an activation test behaves.
- **Base:** one light ignores brightness in Movie Night. Fall back to on or off for that light and note it.
- **Worst:** the check fails or a scene misbehaves. Delete the branch changes, reload scenes. Nothing else was touched.

Rollback: `git revert` the commit on the branch (or delete the branch), then reload scenes. The scenes are removed with no other effect.
